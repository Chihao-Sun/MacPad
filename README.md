# MacPad

**让 iPad 成为 Mac mini 的日常屏幕。**

MacPad 是免费、以 GPL-3.0-only 开源的 macOS 菜单栏工具。它把虚拟屏幕、Apple 随航、高清镜像和自动连接整理成一个应用，适合携带 Mac mini、使用 iPad 工作的场景。

MacPad 在 Mac 登录后工作。第一次配置保留外接显示器，完成配置和无屏验证后，日常可以使用 iPad 显示桌面，无需另装虚拟屏幕软件或连接显示器诱骗器。

## 我们改进了哪些体验

| 功能 | 日常使用时的作用 |
| --- | --- |
| 无外接屏桌面 | 应用保留虚拟屏幕，拔掉实体显示器后仍有可供随航显示的桌面。 |
| 同一镜像桌面 | iPad 与 MacPad 虚拟屏保持镜像，避免鼠标和窗口跑到看不见的扩展桌面。 |
| 登录后自动连接 | 用户开启后，没有实体显示器时自动尝试连接；设备暂未就绪时继续重试。 |
| 有线优先、无线接续 | 插线优先 USB-C，拔线尝试无线，插回数据线后尝试回到有线。切换期间保留显示大小和虚拟桌面。 |
| 临时手动选择 | 可选择自动、USB-C 有线或无线；下次线缆状态变化或重新登录恢复自动，避免忘记改回。 |
| 五档真实高清 | 默认 1344 × 938，实际渲染 2688 × 1876；可调文字大小与桌面空间，并核对实际模式后保存。 |
| 清晰的暂停行为 | “断开”暂停自动连接，“连接”恢复；关闭设置窗口则继续使用。 |
| 菜单栏静默运行 | 无需常驻 Dock，设置窗口关闭后释放界面内容，桌面连接继续保留。 |
| 更容易看懂的状态 | 原生风格设置、当前连接方式、连接记录和具体错误，减少反复翻找系统随航设置。 |

当前设备的拔线测试中，用户观察约 5 秒恢复，日志约 5 秒显示上线、约 6 秒完成稳定校验。恢复时间会受系统与无线环境影响，不承诺零中断或固定秒数。

## 下载与发布状态

当前源码基线为 **V1.2.1 / build27**。项目准备通过 GitHub Releases 提供安装包；当前安装归档为本地 ad-hoc 签名，尚未完成 Developer ID 签名、公证及其他 Mac 的首次安装验证。

正式安装包完成这些步骤后才会标为可公开分发。公开源码可供审阅和自行构建；本地编译成功不代表 Apple 公证或新设备兼容性通过。

## 兼容范围

- 构建架构：Apple Silicon / arm64；未提供 Intel 构建。
- 编译最低目标：macOS 14。这是构建目标，不代表所有 macOS 14 及以上版本均已验证。
- 实际验收：M4 Mac mini、macOS 26.6.2、iPad Pro 11 英寸第二代；iPadOS 具体版本尚未登记。
- 需要满足 [Apple 随航要求](https://support.apple.com/en-ie/102597)，包括同一 Apple 账户和双重认证。有线需要设备信任；无线需要 Wi-Fi、蓝牙、接力和近距离可用。

本版使用系统内部接口，macOS 升级可能改变兼容性。其他机型、屏幕比例和系统版本需要单独验证。

## 第一次配置

1. **先保留外接屏。** 用显示器完成初始设置，准备连接到 Mac 的键盘和鼠标。此时不要直接进入无屏冷启动测试。
2. **准备 Mac 与 iPad。** 确认支持随航，两端登录同一 Apple 账户并启用双重认证。要使用无线接续时，开启 Wi-Fi、蓝牙和接力，保持设备在附近。
3. **固定安装位置。** 将 MacPad.app 放入固定的应用程序目录后再打开，保留一个可启动副本。不要直接从临时解压目录启用登录启动。
4. **先用数据线连接。** iPad 解锁，用能传数据的 USB-C 线直连 Mac；按系统提示信任此 Mac。无需进行访达同步或 iPad 备份。
5. **连接并验收画面。** 打开菜单栏 MacPad，选择目标 iPad，点击“连接”。确认桌面可见，键盘、鼠标能操作；默认显示大小为 1344 × 938。
6. **开启所需自动功能。** 在“自动连接”页开启“没有实体显示器时自动连接”“自动切换有线与无线”“登录 Mac 后启动”。全新安装不会自动注册登录项。
7. **拔掉外接屏测试。** 保持 iPad 插线、解锁，只拔显示器视频线。确认 iPad 仍显示桌面、鼠标能到达可见桌面，再测试无线接续。
8. **单独测试关机与携带。** 保存工作，正常关机后再拔电；重新接电开机，保持 iPad 插线且解锁，用连接到 Mac 的键盘输入开机密码。登录后等待自动连接。出门前完成自己设备上的完整验证，并保留恢复方式。

更详细的配置、日常拔插和恢复流程见 [首次配置指南](docs/首次配置.md)。

## 显示大小

| 桌面大小 | 实际渲染像素 | 用途 |
| --- | --- | --- |
| 1194 × 834 | 2388 × 1668 | 较大文字，已测面板原生像素 |
| 1280 × 894 | 2560 × 1788 | 较大文字 |
| **1344 × 938** | **2688 × 1876** | **默认大小** |
| 1600 × 1118 | 3200 × 2236 | 更多空间 |
| 2388 × 1668 | 4776 × 3336 | 最大桌面空间，渲染负担也更高 |

这些档位按已测的 11 英寸 iPad Pro 比例设置。最终清晰度还取决于面板、系统缩放和随航传输，高清不等于每一档都与面板一对一像素映射。

## 使用边界

- MacPad 不显示 FileVault 开机解锁画面，不保存密码，也不启用系统自动登录。
- 当前 build27 的断开/恢复、高清镜像已验收；历史 build23 通过无实体显示器有线冷启动，最终分发版本仍需重测。
- 完全离线、实际睡眠/唤醒、插线时手动强制无线及其他设备组合尚未分别验收。
- 它不提供跨公网远程桌面，也不把 iPad 变成完整的 macOS 手指触摸屏。
- 如果 MacPad 是唯一显示器，更新或退出前先接上备用显示器。退出会移除当前进程保留的虚拟屏幕。

## 本地构建

在 Apple Silicon Mac 上安装 Xcode 或包含所需 macOS SDK 的命令行开发工具，并准备 Python 3：

```sh
zsh scripts/test.sh
zsh scripts/build.sh
```

应用生成于 `.build/Release.noindex/<VERSION>/MacPad.app`。构建脚本会递增内部 `BUILD`；源码记录的 build27 是冻结交付基线，本地新构建是新的构建，不应冒充原始冻结包。脚本仅生成和本地签名，不自动安装、替换或启动应用。

测试覆盖连接策略与菜单栏几何，不替代真实 iPad、物理拔插或冷启动验收。首次测试 App 仍需保留可用显示器。
