# 隐私与本地诊断

MacPad V1.3.0 使用本机偏好设置保存显示大小、设备选择和自动连接选项，并读取系统提供的设备及显示器状态。按设备名称在本地保存原生屏幕宽高和已选择的桌面大小，用于下次连接；不采集硬件序列号或硬件 UUID。

诊断文件为 `~/Library/Application Support/MacPad/status.json` 和 `latest-session.log`。状态变化时写入，可能包含设备/显示器名称、安装路径、进程编号、连接方式、时间、显示模式和错误信息。它们保留在本机，不自动发送给项目维护者。

当前代码不接入自有服务器、广告分析、自动上传或自动更新服务；不保存用户登录密码、不执行 iPad 备份，也不将画面保存为录像文件。画面传输、Apple 账户与随航系统服务由 Apple 管理，不能将 MacPad 无自有上传服务的说明推广为所有系统服务都不联网。

登录启动由用户主动开启。MacPad 不修改 FileVault、系统自动登录、远程管理、VPN、代理、DNS 或路由。

提交问题前先检查日志和截图，删去个人设备名称、路径及桌面中的私密内容。不要上传密码、Token、证书、设备标识或未经检查的整个诊断文件夹。

卸载前先接备用显示器，关闭应用内登录启动，再退出和移除 App。需要时可自行移除上述 MacPad 本地诊断目录。删除应用文件不等于清除 macOS 保存的全部历史记录。
