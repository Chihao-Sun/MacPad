# 第一次把 iPad 配成 Mac 屏幕

[English](GETTING_STARTED.md) | **简体中文**

首次配置请保留外接显示器。MacPad 的无屏使用发生在 macOS 登录后；FileVault 密码仍要用连接到 Mac 的键盘输入。

## 准备

1. 准备 Apple Silicon Mac、支持随航的 iPad、Mac 键盘鼠标、外接显示器，以及一条能传数据的 USB-C 线。仅充电的线不能完成有线连接。
2. 确认两端满足 [Apple 随航要求](https://support.apple.com/en-ie/102597)，登录同一 Apple 账户并开启双重认证。
3. 要用无线时，开启 Wi-Fi、蓝牙和接力，保持设备在附近。Mac 不应共享互联网连接，iPad 不应共享移动数据连接。无线异常时，可按 Apple 的排查指引先让设备连接同一 Wi-Fi。
4. MacPad 不需要开启远程管理、远程登录或远程 Apple 事件；不要为连接而关闭 FileVault 或修改系统自动登录。

## 安装与第一次连接

1. 从 GitHub Releases 下载 DMG，打开后把 MacPad.app 拖入 Applications，再从固定应用程序目录启动。当前包为 ad-hoc 本地签名、未公证；首次拦截请按 README 链接的 Apple 系统指引检查这个 App，不关闭系统整体安全保护。
2. 保留一个应用副本，从固定位置开启登录启动，避免解压目录和应用程序目录中出现两个运行实例。
3. 解锁 iPad，USB-C 数据线直插 Mac。按提示信任此 Mac、允许系统要求的配件连接。不要在访达点击备份或同步；MacPad 不需要这些操作。
4. 点击顶部菜单栏 MacPad 图标，选择“打开 MacPad”。在“连接与显示”页选择你的 iPad，点击“连接”。
5. 确认 iPad 出现 Mac 桌面，试着移动鼠标、打开窗口和使用键盘。连接成功后默认使用同一镜像桌面，设置页的“iPad 屏幕”显示系统识别的原生像素。
6. 在“显示大小”选择适合自己的档位。软件按 iPad 原生像素与比例生成选项，并按设备保存选择；已测的 11 英寸 iPad Pro 保留 1344 × 938 默认大小。
7. 需要其他尺寸时，选“自定义…”，输入桌面宽度。“保持 iPad 屏幕比例”默认开启，高度会自动计算；也可关闭后分别输入宽高。软件会检查高清画布上限和面板像素覆盖，实际应用并确认镜像后才保存。

## 开启日常自动使用

进入“自动连接”页：

| 开关 | 开启后的行为 |
| --- | --- |
| 没有实体显示器时自动连接 | 登录后或拔掉外接屏后，自动尝试连接 iPad；在有限尝试后等待设备重新就绪，避免重复系统错误窗。 |
| 自动切换有线与无线 | 数据线接入时优先有线，没有数据线时尝试无线。 |
| 登录 Mac 后启动 | 用户进入 macOS 桌面后，在菜单栏启动 MacPad。 |

全新安装不会自动替你注册登录项。系统提示需要允许时，在“系统设置 → 通用 → 登录项”中核对 MacPad。

配置完成后关闭设置窗口即可，应用继续运行。不要将“关闭窗口”和“退出 MacPad”混同。

## 分别完成三次验证

1. **拔外接屏：** 保持 iPad 插线且解锁，只拔外接显示器视频线；确认 iPad 画面和键盘鼠标仍正常。失败时接回显示器恢复。
2. **拔插数据线：** 在无线条件就绪时直接拔 iPad 数据线，不点击“断开”；等待画面恢复，再插回线确认有线接续。可能短暂黑屏；无线恢复失败时可插回数据线等待重试。
3. **关机后重开：** 保存工作并正常关机，关机完成才拔电。重新接电开机，iPad 保持插线、解锁，用连接到 Mac 的键盘输入开机密码并回车，登录后观察自动连接。首次无屏试验请把恢复用显示器放在手边。

这些验证分别证明拔屏、传输切换和登录后恢复，不能用一次手动连接成功替代。完全没有互联网的场景还需要另测，现版本不承诺已验证离线可用。

## 日常怎么切换

- **有线切无线：** 保持无线条件可用，直接拔数据线。
- **无线切有线：** 直接插回 USB-C 数据线。
- **临时指定方式：** 在“连接方式”中选有线或无线；选择自动、下次线缆状态变化或重新登录后恢复默认。
- **暂时不用 iPad：** 点击“断开”，自动连接暂停；需要时点击“连接”恢复。

## 更新、退出与卸载

MacPad 是唯一显示器时，先接备用显示器，再更新或退出。退出进程会移除它保留的虚拟屏幕，可能导致 iPad 画面断开。

卸载前关闭应用内“登录 Mac 后启动”，退出后移除 App。诊断文件是否另行清理由用户决定，见 [隐私说明](隐私说明.md)。

## 连接失败后

系统请求未结束时，MacPad 不会再发起第二个连接。连续三次未建立稳定桌面后，后台尝试暂停，等待设备重新出现、线缆插拔、Mac 唤醒或手动点击“连接”。普通刷新和定时检查不会重新启动无限重试。解锁 iPad 并重新插线可以提供新的连接机会；系统自身仍可能显示单次失败提示。
